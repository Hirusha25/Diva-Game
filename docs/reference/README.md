# Visual references

The running world is built to match these images. Check every world change
against them (portrait phone first, then landscape).

- `world-portrait.webp` – master reference: sky gradient, cloud placement, tree
  spacing (one row, set back behind the wall, trunks hidden), small flower
  bushes at the wall base, yellow wall with stone cap, paved footpath, chunky
  black/white kerb, bus shelter, dappled tree shadows on the road.
- `world-sky.webp` – sky colour stops (deep blue zenith to pale cyan horizon).
- `road-texture.png` – asphalt grain, dash proportions, leafy shadow look.

Rules distilled from feedback:
- No bare green ground visible anywhere beyond the wall.
- Nothing pokes through or over the wall except tree canopies.
- Trees and bushes stay sparse; do not crowd.
- Clouds stay white and move with parallax; not too many at the start.
